Тест API def test_create_personal_event_negative выявил баг в системе: 
При тестировании API система сохраняет событие, в котором не заполнены все обязательные поля ввода.


Шаги воспроизведения:
1. Создаем json=invalid_body, не указав значение обязательного поля StartAt. Остальные обязательные поля заполнены.
2. Отправляем POST запрос с API_URL_CREATE, headers=API_HEADERS, json=invalid_body
3. Запускаем автотест.


Ожидаемый результат: проверка assert выдаст сообщение: "Ожидалась ошибка 400 или 422, но получен {response.status_code}"
Фактический результат: получен статус код 200 ОК. Система позволяет сохранить событие с пустым полем StartAt. Присваивает ID.
